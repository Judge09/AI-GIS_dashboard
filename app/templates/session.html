AI-GIS vs ModSecurity (OWASP CRS, PL2)

Same payloads, same session, scored by both. ModSecurity returns a binary block/pass (HTTP 403 vs 200), so it has no confidence score to plot — the comparison is on counts.

Probe fidelity: requests are sent with browser-like Accept / Accept-Language headers. Without them CRS rule 920300 (missing Accept header) scores every request and ModSecurity appears to block 100% of traffic — a measurement artifact, not a WAF result. scripts/12_evaluate_modsec_baseline.py sends only a User-Agent and is affected; align it before quoting its specificity.
