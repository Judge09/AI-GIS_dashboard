Reading condition 5 correctly

LSTM Plus Meta No RF shows F1 = 0.0 at the fixed 0.5 threshold while its AUC-ROC is 1.0. Those are not in conflict: zeroing the RF input shifts every meta-learner probability below 0.5, so the ranking stays perfect but the fixed cut-off classifies everything as benign.

At its own best threshold that condition reaches F1 ≈ 0.9998 — so the LSTM branch alone carries nearly all the discriminative signal. Report the AUC-ROC (or the tuned-threshold F1) for this condition; the 0.0 is an artifact of the threshold, not a finding.

What the ablation supports

The clean test set is saturated — conditions 1, 2, 4, 5 and 6 all reach AUC-ROC 1.0. The only condition that visibly degrades is LR on 11 base features (F1 0.9888, FPR 0.87%), which is the evidence that the engineered structural and n-gram features matter.

This study therefore justifies the feature engineering, not the stacking. The case for stacking lives in the evasion and hard-benign stress tests, where the components genuinely disagree.
