What is not claimed here

A paired McNemar test between the two systems on these rows is not computed. The stored ModSecurity report retains only {{ ms.false_alarms_list_len }} of its {{ ms.false_alarms_stated_fp }} false alarms as individual rows, and the WAF container was not available to regenerate the full per-row record. A paired test needs per-row agreement, so the comparison above is reported as aggregate rates only. Fabricating the missing rows would produce a p-value with no measurement behind it.
