How to read these numbers

Every stacked metric moved in the right direction, but none of them clears p < 0.05 on a paired test across the {{ cur.multiseed.seeds | length }} seeds ({{ cur.multiseed.seeds | join(", ") }}) — the best is F1 at p = {{ sig.f1_p }}. The LSTM branch is non-deterministic on CPU, so the stacked ensemble carries that variance.

The Random Forest branch improvements are significant: FPR p = {{ cur.multiseed.significance.rf.fpr_p }}, F1 p = {{ cur.multiseed.significance.rf.f1_p }}, AUC p = {{ cur.multiseed.significance.rf.auc_p }}. That is the defensible claim from this cycle: the corpus expansion and the keyword-sequence features measurably improved the RF, and the ensemble improved directionally without statistical confirmation.
