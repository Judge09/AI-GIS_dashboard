b = cases the first model got right and the second got wrong; c = the reverse. McNemar's test asks whether that disagreement is lopsided enough to be more than chance.

How to report this in Chapter 4

On this test set the stacked ensemble is not statistically distinguishable from its base models — every comparison returns p > 0.05. The honest claim is that stacking does not degrade clean-set performance while improving robustness on the stress and evasion sets; it is not "significantly better on the test set," because these numbers do not support that.

The test set is saturated (all models at or near F1 = 1.0), so McNemar's test has almost no disagreement to work with. To make a significance claim, run the comparison on the harder sets where the models genuinely differ.
