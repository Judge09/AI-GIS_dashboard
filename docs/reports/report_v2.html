2What we actually changed

  • ✓
    Gave the Random Forest real structure to look at, not just counts. Before, it only counted symbols. Now it also checks for the actual shape of an attack — like "X equals X" (the classic SQLi trick), a quote sitting right before "OR"/"UNION", or an actual HTML tag opening. Ordinary text almost never has these shapes, even when it has plenty of symbols.
  • ✓
    Added 300 "sub-word" pattern features (technically: character n-gram TF-IDF) so the model can pick up on structural fingerprints we didn't think to hand-code ourselves.
  • ✓
    Actually trained the full 3-part system — Random Forest + LSTM + the meta-learner that blends them — instead of testing each piece alone. This is what did most of the heavy lifting: the meta-learner learned to trust whichever model was actually right for each case.
  • ✓
    Found and used the model's own confidence gap. Every real attack was caught with at least 60% confidence; most ordinary text scored much lower. That gap is real headroom a production system should use.
